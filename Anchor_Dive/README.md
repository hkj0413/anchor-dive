# Desperado_Re — SG Godot Prototype 01 / 물리 60Hz · 화면 120FPS

## 목적
Steam 상업 출시를 전제로 한 새 프로젝트의 첫 조작 프로토타입입니다. 최종 캐릭터 디자인을 확정하기 전에 **SG의 이동·점프·360° 조준·공격·반동 이동·방패·장전 감각**만 검증하도록 범위를 제한했습니다.

## 기준
- Godot 4.7.x / GDScript
- 디자인 기준 해상도: 1920×1080
- 횡스크롤 사이드뷰
- 몬스터 / 로그라이트 강화 / 스토리 / 상점 / 보스 없음
- 캐릭터 최종 아트 없음: 현재 외형은 코드로 그린 독자적인 테스트 도형
- 외부 이미지/사운드 리소스 사용 없음

## 조작
- A / D: 이동
- Space: 점프
- Mouse: 360° 조준
- Left Mouse: 공격용 산탄 (8 pellet)
- Right Mouse: 반동 이동용 사격
- Shift: 방패 전개
- R: 한 발씩 장전
- S + Space: 일방향 발판 내려가기

## 현재 SG 핵심 구조
- 탄약 6발
- 좌클릭과 우클릭은 같은 탄약을 사용
- 좌클릭은 플레이어 이동에 거의 영향을 주지 않는 공격용
- 우클릭은 조준 반대 방향으로 강하게 이동하는 기동용
- Shift 방패 중 이동/점프/우클릭 반동 거리가 감소
- 방패는 에너지를 소비하고 비전개 시 재충전
- R 장전은 한 발씩 진행되며 공격/반동 사격으로 즉시 중단 가능

## 실행
1. Godot 4.7.x를 설치합니다.
2. Godot Project Manager에서 이 폴더의 `project.godot`를 Import 합니다.
3. 프로젝트를 열고 F6이 아니라 F5로 실행합니다.

## 물리 60Hz / 화면 120FPS
- 이동·점프·충돌·산탄 레이캐스트·반동·장전·방패 에너지는 고정 60Hz에서 계산합니다.
- 화면은 최대 120FPS이며 카메라·총의 시각적 조준·조준점은 렌더 프레임마다 갱신합니다.
- 캐릭터 표시 위치와 카메라 목표는 직전/현재 물리 위치 사이를 보간합니다. 총의 시각적 조준은 카메라 갱신 후 마우스를 읽으며, 사격 판정은 물리 루프에서 별도로 읽습니다.
- 스폰·낙하 리셋 시 보간 기록과 카메라 추적을 초기화합니다.
- VSync를 유지합니다. 60Hz 모니터에서는 일반적으로 60FPS로 제한되며, 실제 120FPS는 모니터 주사율과 PC 성능에 따라 달라집니다.
- 이동 속도·충돌 크기·탄약·공격 간격·장전 시간·방패 수치는 기존과 같습니다. 스프라이트 재생 FPS는 별도이며 이번 변경에 포함하지 않습니다.

### 구현 위치
- `project.godot`: 화면 상한 120FPS, 물리 60Hz, 물리 보간 활성화
- `scripts/sg.gd`: 물리 처리와 표시 위치/카메라 목표 처리 분리
- `scripts/sg_visual.gd`: 카메라 갱신 뒤 렌더 프레임마다 총 조준 갱신
- 표시 노드와 카메라는 물리 부모의 변환을 상속하지 않고 직접 보간하므로 중복 보간을 피합니다.

### 확인 방법
1. 120Hz 이상 디스플레이에서 실행하고 Godot 디버거의 모니터로 FPS를 확인합니다.
2. A/D 이동·점프·벽 충돌 중 카메라와 몸체가 부드럽게 움직이는지 확인합니다.
3. 이동 중 마우스로 원을 그리며 총 방향과 조준점이 맞는지 확인합니다.
4. 화면 상한만 60/120으로 바꾸어 이동 속도, 공격 간격, 장전 시간이 같은지 비교합니다. 물리는 60Hz를 유지합니다.

Godot 4.7.2의 헤드리스 실행 및 물리 회귀 검증을 통과했습니다. 검증 범위와 재실행 방법은 `VERIFICATION.md`에 있습니다. 기존 코드의 엔진 메서드 이름 충돌과 실수형 추론 오류도 함께 수정했습니다.

## 이번 버전에서 검증할 것
1. 175px 전후 SG 크기가 1920×1080에서 적절한가
2. 기본 이동과 점프가 답답하지 않은가
3. 우클릭 반동 이동의 세기가 조작 가능한 수준인가
4. 방패 중 이동 감소가 지나치지 않은가
5. 6발을 공격과 이동에 함께 쓰는 구조가 재미있는가
6. 한 발씩 장전하면서 중간에 공격으로 끊는 리듬이 좋은가

## 저작권/리소스 상태
이 프로토타입에는 기존 Desperado의 이미지, 음악, 효과음, 캐릭터 스프라이트를 포함하지 않습니다. 시각 요소는 Godot Drawing API로 생성한 테스트 그래픽이며 WAV 효과음은 이 프로젝트를 위해 절차적으로 합성한 새 파일입니다. 최종 Steam용 캐릭터/배경/UI 디자인은 이후 별도로 독자 제작합니다.
